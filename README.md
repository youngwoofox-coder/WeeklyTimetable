# 📅 주간 시간표

일주일(월~일) 일정을 한눈에 보는 안드로이드 앱입니다.
드래그로 일정을 만들고, 홈 화면 위젯으로 이번 주 일정을 바로 확인할 수 있습니다.

## 주요 기능

- **주간 시간표** — 07:00 ~ 24:00, 30분 단위. 오후는 12를 뺀 값(13시 → 1)으로 표시
- **드래그 편집** — 빈 칸을 끌어서 추가, 블록을 끌어서 이동, 블록 아래쪽을 끌어서 길이 조절
- **반복 일정** — 기간과 요일을 골라 한 번에 등록
- **색상 10가지** — 일정마다 색 지정
- **홈 화면 위젯** — 4×5 크기 기준, 이번 주 시간표 표시
- **다크 모드** — 휴대폰 설정에 따라 자동 전환

## 사용법

### 일정 추가하기
| 방법 | 하는 법 |
|---|---|
| 버튼 | 오른쪽 위 **+ 일정** → 일정명·날짜·시간 입력 → 저장 |
| 드래그 | **드래그 편집** 켜기 → 빈 칸을 세로로 끌기 → 입력창에서 저장 |

- 시간은 24시간제 `HH:mm`으로 입력하며, **00분 / 30분**만 가능합니다.
- 같은 날 시간이 겹치는 일정은 저장되지 않습니다. (끝과 시작이 맞닿는 건 괜찮아요)

### 일정 수정·삭제
- 시간표의 블록을 누르거나 **일정 목록**에서 선택하면 수정창이 열립니다.
- **드래그 편집** 중에는 블록을 끌어 날짜·시간을 옮기고, 아래쪽을 끌어 끝나는 시간을 바꿀 수 있습니다.
- 드래그 후에도 입력창에서 **저장**을 눌러야 반영되고, **취소**하면 원래대로 돌아갑니다.

### 반복 일정
일정 추가창에서 **기간 동안 반복**을 체크하고 시작일·종료일·요일을 고릅니다.

> 예) 10/12 ~ 10/23, 월·수 → 12일, 14일, 19일, 21일 총 4건 등록

- 매일 반복은 7개 요일을 모두 선택하면 됩니다. (최대 2년 범위)
- 반복 일정은 **날짜별로 따로 저장**됩니다. 한 날짜를 수정해도 다른 날짜는 그대로입니다.
- 삭제할 때는 **이 날짜만** 또는 **반복 전체** 중 고를 수 있습니다.
- 반복 기간 중 한 날짜라도 다른 일정과 겹치면 전체 등록이 취소되고, 겹치는 날짜를 알려줍니다.

### 위젯
- 홈 화면 빈 곳을 길게 누름 → **위젯** → **주간 시간표** 추가
- 항상 **이번 주**를 보여주며, 누르면 앱이 열립니다.
- 칸이 좁아 긴 일정명은 잘릴 수 있습니다. 자세한 내용은 앱에서 확인하세요.

## 알아두면 좋은 점

- **저장 위치**: 모든 일정은 휴대폰 안에만 저장됩니다. 서버로 보내지 않습니다.
- **백업 안 됨**: 앱을 삭제하거나 앱 데이터를 지우면 일정도 사라지고, 휴대폰을 바꿔도 옮겨지지 않습니다.
- **위젯 갱신**: 앱에서 저장하면 바로 반영됩니다. 주가 바뀔 때는 휴대폰 상황에 따라 반영이 조금 늦을 수 있습니다.

## 빌드 & 설치

**필요한 것**: Android Studio, JDK 17, Android SDK 35

```sh
# 테스트 + APK 빌드 (Windows는 gradlew.bat)
./gradlew testDebugUnitTest assembleDebug
```

**휴대폰에 설치하기**
1. 휴대폰에서 **개발자 옵션 → USB 디버깅**을 켭니다.
2. USB로 연결하고 휴대폰에 뜨는 **디버깅 허용**을 누릅니다.
3. Android Studio에서 휴대폰을 선택하고 **Run ▶**을 누릅니다.

## 프로젝트 구조

```
app/src/main/java/com/example/timetable/
├── MainActivity.kt            # 메인 화면, 일정 입력창
├── ScheduleViewModel.kt       # 저장 처리, 위젯 갱신 요청
├── data/
│   ├── ScheduleItem.kt        # 일정 모델, 시간 범위·색상, 입력 검사, 반복 생성
│   └── ScheduleRepository.kt  # 휴대폰 내 저장 (DataStore)
├── ui/
│   └── WeeklyTimetable.kt     # 주간 시간표 화면, 드래그 편집
└── widget/
    ├── TimetableWidget.kt     # 홈 화면 위젯
    └── WidgetRefreshWorker.kt # 위젯 갱신 작업
```

**사용 기술**: Kotlin · Jetpack Compose · Glance(위젯) · DataStore · WorkManager
